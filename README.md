# 2048 Drop — 下落合并型 2048

数字下落 + 十字合并 + 无限连锁的网页小游戏。纯原生 HTML/CSS/JS，无框架无构建，打开 `index.html` 即玩。

**玩法：** 数字从顶部下落，过程中可以左右移动 / 加速 / 直落。落地后与相邻（下/左/右连通）的相同数字合并，**无限连锁**直到没有可合并的组。

## 操作方式

- **PC：** ← → 移动 · ↓ 加速 · 空格直落 · 1-7 选列 · P 暂停 · N 新游戏
- **手机：** 点击/触摸棋盘任意列直落到该列，或用下方 ◀ ▼ ▶ 按钮

## 特色

- 8 行 × 7 列棋盘（自动 600ms/格，按住 ↓ 加速至 90ms/格）
- 十字无限连锁合并 + 多块同值一次性合并 + Combo 加成
- **任何一列堆到顶即游戏结束**（俄罗斯方块式规则）；落到顶格一瞬触发的连锁消除可以救场
- **智能数字生成**：上限封顶（绝不超过盘面最大数字）、小数字几何衰减为主、盘面有搭档加权、危险时偏向小数字自救
- localStorage 保存最高分和进度
- Web Audio 合成音效，无需外部文件
