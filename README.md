# 2048 Drop — 下落合并型 2048

数字下落 + 十字合并 + 无限连锁的网页小游戏。

**玩法：** 数字从顶部下落，过程中可以左右移动 / 加速 / 直落。落地后与下方、左方、右方相同数字合并，**无限连锁**直到三个方向都不匹配。

## 操作方式

- **PC：** ← → 移动 · ↓ 加速 · 空格直落 · 1-8 选列 · P 暂停
- **手机：** 点击/触摸棋盘直落，或用下方 ◀ ▼ DROP ▶ 按钮

## 特色

- 12×8 棋盘，节奏从容（自动 1300ms/格，加速 140ms/格）
- 十字无限连锁合并 + Combo 加成
- 满列可合并救活机制
- 达到 2048 后可继续挑战更高数字
- localStorage 保存最高分和进度
